# СТАТУС Премиум — верстка (тестовое задание, задача 1)

Сверстанная страница по макету Figma («Статус Премиум», фрейм `Desktop`, 1440px).
Реализовано на чистых HTML/CSS/JS (без фреймворков).

## Структура

```
site/
├─ index.html          разметка страницы
├─ css/style.css       стили + адаптив + анимации
├─ js/script.js        валидация форм, попап, анимация появления секций
├─ assets/             изображения, SVG-иконки, favicon
└─ README.md
```

## Как открыть

Просто откройте `index.html` в браузере. Для локального сервера (рекомендуется):

```
# Python
python -m http.server 8000
# затем http://localhost:8000
```

## Что реализовано

- **Секции**: шапка, hero, «Премиальное обслуживание», «Привилегии», «Запланировать встречу», «Индивидуальная поддержка», «Как стать премиальным клиентом», «Вы получаете», подвал.
- **Адаптивная верстка**: брейкпоинты `1200 / 1024 / 900 / 640`. Сетки перестраиваются (4 → 3 → 2 → 1), hero «складывается» в столбик на ≤900px.
- **Анимации**: hover/focus на интерактивных элементах (кнопки, карточки, ссылки), плавное появление секций при прокрутке (`IntersectionObserver`); при `prefers-reduced-motion` отключается.
- **Форма 1** («Заказать звонок»): при отправке имитируется **неуспешная** отправка из-за ошибок ввода (подсветка полей + сообщения).
- **Форма 3** («Стать клиентом»): при корректной отправке показывается **попап** об успехе (закрытие по Esc/клику по фону, возврат фокуса).
- **Доступность**: `focus-visible`, `aria`, управление фокусом попапа.

## Примечания

- Шрифт — Lato (Google Fonts). Без интернета подставляется системный.
- Анимации и валидация форм работают без падения при отключённом JS (формы уходят нативным сабмитом).
- Файлы ассетов названы латиницей для корректной загрузки на тестовую среду (Bitrix/nginx).
